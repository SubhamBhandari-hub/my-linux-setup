📚 What I’ve Actually Learned

1\. Linux is About Control, Not Commands



👉 Commands are just tools.

✔️ Real skill = controlling system behavior.



2\. File System is Everything

/home → user data

/etc → configs

/proc → live system data

/var/log → logs



👉 Understanding structure > memorizing commands



3\. Permissions Matter More Than I Thought

chmod 755 script.sh



✔️ I learned:



Who can read/write/execute matters for security

4\. Processes Are the Heart of the System

ps aux

top



✔️ I learned:



Everything running = process

Attacks often hide as processes

5\. Networking = Visibility

ss -tuln

ping

dig



✔️ I learned:



Systems communicate constantly

Open ports = potential attack surface

6\. Searching is a Superpower

grep

find



✔️ I learned:



Finding information fast is critical

7\. Mistakes Teach More Than Tutorials



👉 Breaking system taught me more than reading docs.



8\. Simplicity > Complexity



👉 Most powerful commands are simple:



ls

grep

cat



But used smartly.
